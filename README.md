# FinOps Simulator

Aplicativo Android para simular os custos de projetos e recursos em nuvem.

## Funcionalidades

- Cadastro de projetos.
- Cadastro de recursos alocados.
- Cadastro de tipos de recursos.
- Armazenamento local dos dados.

## Tecnologias

- Android SDK 36
- Java 11
- Gradle Kotlin DSL
- AndroidX, Material e SQLite

## Como executar

1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute a configuração `app` em um emulador ou dispositivo Android.

Requisito mínimo: Android 7.0 (API 24).
